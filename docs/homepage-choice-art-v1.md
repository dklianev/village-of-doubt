## Optimization

Normal `pnpm optimize:assets` now regenerates both full and mobile WebPs from
`assets/game-art-source/homepage/choice-{family}-v1.png`. It uses the existing
generator runner and canonical encoder; no manual mobile staging, additional
source masters, dependencies, or command changes are needed.

The mobile-width rule in `scripts/optimize-assets.mjs` matches only
`homepage/choice-werewolf-v1.png` and `homepage/choice-mafia-v1.png`. Other
folders, families, versions, suffixes, and recursive mobile paths are excluded.
The existing dedicated-mobile-source precedence is preserved.

- The source masters are 960 x 640 palette PNGs, originally trimmed using
  quality 78, compression level 9, effort 10, adaptive filtering, under 500 KiB.
- Full WebPs retain the existing quality 82 default, effort 6, smart
  subsampling, and 360 KiB budget. The masters need no further resizing.
- Mobile WebPs use the existing one-pass derivative encoder: width 720,
  aspect ratio preserved without enlargement, quality 70 with budget fallback,
  effort 6, smart subsampling, and the existing 180 KiB mobile budget. These
  masters produce 720 x 480 output at the existing mobile URLs.
- No AVIF or public PNG is required by the optimizer for these `choice-*` names.

The isolated regression test copies only the two repository masters to a
temporary tree and invokes the real optimizer there. It verifies both mobile
dimensions and budgets, unchanged source bytes, and exactly four runtime
WebPs. It then deletes the temporary mobile files and proves a second run
recreates identical bytes while preserving the full outputs. The shared asset
catalog is never regenerated by this test.

## Generation Prompts

### Werewolf

```text
Use case: historical-scene.
Asset type: original premium homepage game-choice illustration, landscape 1536x1024 (3:2), a single complete image, not a UI mockup.
Primary request: a Bulgarian mountain village at blue hour, a wary conversation among FOUR adult villagers on an open rough-timber village porch around a rough wooden table. A believable middle-aged woman with a subtly embroidered linen blouse, a younger adult man in a muted green wool cloak, an older bearded man and another adult woman. They exchange expressive suspicious sideways glances with each other, as if one is hiding a secret; natural believable adult faces and restrained hand gestures, no one looking at the viewer. Convey social deduction and human uncertainty, not an empty room.
Scene/backdrop: recognizable old Bulgarian mountain houses with pale plaster and timber, distant forested mountain ridge and muted evergreen silhouettes visible to the upper left beyond the porch. One small hanging lantern makes faces readable with candle-gold illumination. Subtle embroidered fabric and rough wool, weathered timber.
Style/medium: high-quality hand-painted cinematic historical game illustration, nuanced painterly oil/gouache brushwork and tactile materials, carefully modeled faces, atmospheric but clearly legible. Sophisticated and grounded, not glossy 3D, not photography, not cartoon. Match the world of a detailed hand-painted Bulgarian folk-mystery board game.
Composition/framing: landscape 3:2, compose to preserve all four faces inside the central 80 percent of width for centered 4:3 and 340x260 crops. Group figures across middle-upper to upper-right, heads between roughly 14% and 40% image height, all whole heads comfortably within frame. Upper half carries the village and facial story. View across the near edge of the table, foreground table shadow and subdued fabric fill the lower 45 percent as a naturally quiet darker field for later UI text; no important prop or face in that lower field. Lower field has restrained visible texture and no artificial solid overlay. Top scene must be clear and reasonably luminous, not murky.
Lighting/mood: cool blue-hour skylight, muted forest green, small restrained candle-gold accents, human skin tones; tense and inviting.
Constraints: no actual werewolf, no monster close-up, no gore, no violence, no weapons, no eyes glowing, no text of any kind, no letters, no numbers, no readable symbols, no logo, no frame, no border, no watermark. No oversized moon, no orange/brown tavern palette, no split composition, no collage.
```
