07 / Автоматизация

PR check за нарушения.

Този grep се пуска в CI. Намери ли забранена дума — PR не минава.

scripts/check-dictionary.sh
#!/usr/bin/env bash # check-dictionary.sh — блокира PR ако открие забранени термини в потребителски facing strings. set -e FORBIDDEN=( "Match" "Lobby" "Leaderboard" "Profile" "Dashboard" "Settings" # English — БГ е „Настройки" "Sign in" "Log in" "Log out" "Loading…" "Coming soon" "TODO" # допустимо само като // TODO(design): ) SEARCH_PATHS=( "apps/web/app" "apps/web/components" "packages/ui" ) FOUND=0 for word in "${FORBIDDEN[@]}"; do MATCHES=$(grep -rn --include="*.tsx" --include="*.ts" \ --include="*.mdx" --include="*.md" \ -i "$word" "${SEARCH_PATHS[@]}" || true) if [ -n "$MATCHES" ]; then echo "✗ Забранен термин „$word" намерен в:" echo "$MATCHES" FOUND=1 fi done if [ "$FOUND" = "1" ]; then echo "" echo "Виж docs/dictionary.md за правилните термини." exit 1 fi echo "✓ Речникът е чист."

Този скрипт се извиква от pnpm verify и от GitHub Actions. Изключения се добавят в scripts/dictionary-allowlist.txt (напр. файлове в __tests__).
