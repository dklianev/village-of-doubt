06 · Done definition

Какво значи „готово".

Без този документ всеки PR ще има различна интерпретация на „готово". Тук имаш базови критерии за всяка страница, плюс страница-специфични acceptance. Codex проверява тези checkbox-и преди да отвори PR. Reviewer ги проверява повторно — нарушение блокира merge.

Страници · 23 Универсални критерии · 14 Страница-специфични · ~120 Visual regression · 3 viewports × 1-4 states
00 / Универсални

Тези 14 критерия се прилагат към всеки PR.

Преди да се прочетат page-specific критериите.

  • Build & type safety
  • pnpm typecheck минава без warnings
  • pnpm test минава всички unit + integration тестове
  • Нула any, нула @ts-ignore без обяснителен коментар
  • Visual
  • pnpm regression минава или snapshots са обновени в същия PR
  • Before / after screenshot-и (desktop + mobile) в PR description
  • Проверено на 375px (mobile), 768px (tablet), 1280px (desktop), 1920px (large)
  • Performance
  • Lighthouse Performance ≥85 (desktop) / ≥75 (mobile)
  • LCP ≤2.5s на 4G
  • Bundle delta < +20 KB gzip (или обяснение в PR)
  • Accessibility
  • Lighthouse Accessibility ≥95
  • axe-core: нула violations на всяка докосната страница
  • Keyboard navigation: всеки interactive елемент достъпен с Tab; Esc затваря модали
  • prefers-reduced-motion: проверено — никакви движения над 90ms не се изпълняват
  • Език
  • ./scripts/check-dictionary.sh минава — никакви забранени термини

Home, Werewolf, Mafia, Sign-in, Tutorial. Плюс трите помощни (forgot-password, reset, verify).

Home · /

app/page.tsx

  • Hero е SceneCard density="lg", не custom div

Sign-in · /sign-in

app/sign-in/*

  • Wood-grain background се запазва (сигнатура)

Tutorial · /tutorial

app/tutorial/*
  • Прогрес
  • Прогрес индикаторът е PhaseStrip (5 медальона), не точки
  • Сцени
  • Всяка от 6 сцени има 3–5 sec micro animation в hero (gated by reduced-motion)
  • Caption card има само title + 1–2 параграфа + eyebrow
  • Навигация
  • Arrow keys ← → работят за prev/next
  • „Прескочи" вдясно горе, отваря Dialog за потвърждение
  • Последна стъпка води към „Седни на първата си маса", не „Влез"
  • Feedback модалът се отваря СЛЕД завършване, не по време

Forgot / Reset / Verify · auth peripheral

app/forgot-password app/reset-password app/verify-email
  • Трите страници ползват общ „писмо на масата" template
  • Иконография: восъчен печат, не „икона на ключ"
  • Verify-email success: анимация на счупен печат (gated by reduced-motion)
  • Reset token expired: empty state „Това писмо е стояло твърде дълго."
03 / Sprint 3 · Game core

Acceptance за играта.

Най-критичния спринт. Visual regression покритие тук е задължително.

Play room · /play (всички 4 сцени)

app/play/* components/play/scenes/*
  • Архитектура
  • play-room-client.tsx разделен на 4 файла, всеки < 25 KB
  • Общ state машина в useGameMachine.ts — сцените са pure render
  • Сцена 1: Лоби
  • Играчите подредени с VoteCircle компонент (mode=idle)
  • Код на стаята огромен, copy-to-clipboard, QR sheet при click
  • Manual role builder с 3 preset бутона + accordion за advanced
  • Сцена 2: Разкриване на роля
  • Card flip анимация (rotateY 180°→0°, duration: stage, easing: card)
  • Reduced-motion: crossfade без rotate
  • Auto-hide CTA „Запомних" след 5 sec на спящ режим (visibility API)
  • Сцена 3: Нощ
  • Background gradient е --surface-scene-deep с индиго accent
  • За активни роли: action selector + timer (mono, 02:14 формат)
  • За пасивни роли: „спиш" screen с breathing animation (gated)
  • PlayerDiary видим в right rail (desktop) / drawer (mobile)
  • Сцена 4: Ден / Гласуване
  • Background gradient мени към gold accent
  • VoteCircle активен (mode='voting'), tap = vote, long-press = защита
  • След гласуване — резюме като „вестник заглавие" преди следваща нощ
  • Persistent UI
  • PhaseStrip на дъното, винаги видим
  • Mobile: bottom tab bar (Маса / Роля / Архив) + persistent „Изход"
  • Disconnect: toast „Сервърът те чака. Не бързай.", auto-reconnect
  • Visual regression
  • 4 snapshots × 2 viewports = 8 нови baseline images

Lobby (списък) · /lobby

app/lobby/*
  • EmptyState (empty-chair) при липса на стаи
  • Карта на стая показва: код, домакин, режим, брой/макс играчи
  • „Създай стая" FAB в долен десен ъгъл (винаги достъпен)
  • Филтър по режим — segmented control
  • Live update — нови стаи се появяват без refresh

Roles · /roles

app/roles/*
  • Layout е „колода от карти", grid с 3-4 колони (responsive)
  • Click отваря Sheet с пълно описание
  • Филтър по фракция — segmented control (Селяни/Върколаци/Вампири/Самостоятелни)
  • Search ⌘K с fuzzy matching

  • Аватар е избор от 8 предефинирани портрета

History · /history

app/history/*

06 / Sprint 6 · Periphery

Acceptance за периферията.

FAQ, Privacy, Terms, Status, error pages.

FAQ · /faq

app/faq/*
  • Search bar „Питай огъня…" с ⌘K и fuzzy match
  • Категории като „глави на книгата" с римски цифри
  • Всеки въпрос има shareable link ?question=slug
  • Никакви emoji в категориите
  • EmptyState за search no results: „Огънят не познава този въпрос."

Privacy & Terms · /privacy · /terms

app/privacy/* app/terms/*
  • Layout: парчмент с восъчен печат, дата на влизане в сила
  • Reading time индикатор горе („≈ 8 мин")
  • ToC в страничен rail (desktop) или accordion (mobile)
  • Последна обновена дата в горен десен ъгъл
  • Архив на предишни версии (линк в долен ъгъл, не скрит)

Status · /status

app/status/*
  • Един голям индикатор: „Селото работи" / „Селото е тихо" / „Селото спи"
  • 3 услуги: Маса (game server) · Архив (DB) · Входове (auth)
  • 72-часова графика с точки на 30 мин интервал
  • RSS feed link за Discord интеграция
  • Incident history като кратки сводки, не лог

Error pages · /offline · 404 · 500

app/offline app/not-found.tsx app/global-error.tsx
  • Offline: „Селото потъва в мъгла." + auto-retry indicator
  • 404: „Тази уличка не съществува в картите ни." + Към началото / Доклад
  • 500: „Нещо се счупи в архивите." + support code + Опитай отново / Доклад
  • Без stack trace в production
  • И трите страници ползват SceneCard hero, не custom layout
