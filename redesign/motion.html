Движение с тегло.

Анимациите в селото никога не правят shoo-wee-pop. Те носят тегло, бавно, като свещ. Тази система фиксира пет durations, четири easing криви, и дванадесет специфични типа анимация — всеки със собствено име, продължителност и употреба.

04 / Reduced motion

Какво се случва при опцията „по-малко движение".

Това не е „nice to have". Това е задължителен default — около 8% от потребителите имат активиран prefers-reduced-motion.

  • Всичко с duration < base се запазва (focus rings, button press) — те носят функционална обратна връзка.
  • Всичко с duration ≥ base се намалява до 0.01ms — instant.
  • Ambient анимации (candle flicker, breathing glow, particle drift) се изключват напълно.
  • Crossfade-ове се запазват, но без translate/scale съпровод.
  • Auto-play видеа (hero loops на /werewolf, /mafia) — заменят се със static poster frame.
  • Sound design остава активен — той не е „motion".
apps/web/app/globals.css · global guard
/* Глобален guard. Винаги пръв в globals.css. */ @media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; scroll-behavior: auto !important; } /* Спри auto-play видеата */ video[autoplay] { display: none; } video[autoplay] + .poster-fallback { display: block; } /* Спри ambient SVG анимации */ .candle-flicker, .breath-glow, .particle-drift { animation: none !important; } }
05 / Тестване

Как се проверява в CI.

Playwright симулира prefers-reduced-motion и сравнява screenshot. Ако анимацията все още се изпълнява — fail.

apps/web/__visual__/reduced-motion.spec.ts
import { test, expect } from '@playwright/test'; test.describe('reduced motion', () => { test.use({ /* симулираме prefers-reduced-motion: reduce */ contextOptions: { reducedMotion: 'reduce' }, }); const routes = [ '/', '/werewolf', '/mafia', '/sign-in', '/tutorial', '/account', '/leaderboard', ]; for (const route of routes) { test(`${route} renders without motion`, async ({ page }) => { await page.goto(route); // Изчакай 2 sec — ако нещо се движи още, ще се види await page.waitForTimeout(2000); // Provoke navigation await page.screenshot({ fullPage: true, animations: 'disabled' }); // Втора snapshot след още 500ms; ако се различава — анимация продължава const a = await page.screenshot(); await page.waitForTimeout(500); const b = await page.screenshot(); expect(a).toEqual(b); }); } });
